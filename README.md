# IHSI code


- IHSI_Complete Plotting and Model Training Code.md: Code for plotting all data, IHSI validation, and model training.
- README.md: Data requirements for the execution sequence.
- Figures 1, 3, and 4 are schematic diagrams of the experimental workflow and framework; they are not included in the data plotting code.

## Recommended Order of Execution

1. Install dependencies: numpy, pandas, matplotlib, seaborn, scipy, statsmodels, scikit-learn, tensorflow, openpyxl;
2. Set IHSI_DATA_PATH to the path of the de-identified data files；
3. Optional setting: IHSI_OUTPUT_DIR;
4. Run the corresponding sections in Markdown one by one;
5. Figures 9–10: You can save the corresponding code blocks as separate .py files and run them;
6. The model sections run in the order 10 → 11 → 12 → 13.

## Data and Privacy

The data contains confidential information about the participants and is therefore not publicly available; however, it can be obtained upon request.
